# Auth Cookie

## Запуск

1. Создать `.env` из примера:

   ```bash
   cp .env.example .env
   ```

2. Запустить:

   ```bash
   make up
   ```

3. Залить тестовых пользователей:

   ```bash
   make seed
   ```

4. Открыть **https://localhost/** (сертификат самоподписанный — нажать «Перейти на localhost»).

## Тестовые пользователи

Пароль для обоих — значение `SEED_PASSWORD` из `.env`.

| Email                | Роль   |
| -------------------- | ------ |
| `admin@example.com`  | ADMIN  |
| `client@example.com` | CLIENT |
